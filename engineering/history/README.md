# Engineering history

These files are the original milestone reports produced while the optimizer architecture was being developed and measured. They are retained as the detailed experimental record, including negative results and benchmark evidence.

For the concise public narrative, start with [`../../ENGINEERING.md`](../../ENGINEERING.md). For the current product contract, start with [`../../README.md`](../../README.md).

Historical milestone terminology is preserved as written. In particular, older reports may use **exact** where current public documentation uses the more precise **full production-reference search**. See `ENGINEERING.md` for that distinction.

## Reading order

The milestone sequence runs from M2 instrumentation/search-kernel work through M7B v1.0 readiness. `ENGINEERING_ROADMAP.md` remains at repository root because it is the architecture chronology/authority rather than a single milestone report.
