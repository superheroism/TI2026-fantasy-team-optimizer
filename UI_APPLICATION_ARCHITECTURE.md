# UI / Application Architecture

The browser layer owns user interaction and presentation. It does **not** implement Fantasy rules, scoring, or search policy.

```text
UI state
  ↓
BoardState / OptimizerState
  ↓
OptimizerWorkerClient
  ↓
Web Worker
  ↓
optimizer engine
```

A **Web Worker** runs JavaScript off the browser's main UI thread. This lets expensive optimization continue without freezing controls or rendering.

## Modules

| Module | Responsibility |
|---|---|
| `src/ui/state.ts` | Browser state and optimizer-relevant mutations |
| `src/ui/controls.ts` | DOM events for board, menu, layout, tokens, objective, and theme |
| `src/ui/boardView.ts` | Banner/emblem rendering and recommendation highlights |
| `src/ui/actionView.ts` | Action editors, comparisons, and recommendation display |
| `src/ui/plots.ts` | Score histogram and team-comparison plots |
| `src/ui/optimizerClient.ts` | Worker lifecycle, request IDs, cancellation, stale-result protection |
| `src/ui/app.ts` | Startup and coordination across the modules above |

## State invalidation

Any change that can affect the optimizer goes through `ApplicationState` and triggers one invalidation event. The handler then:

1. invalidates the active worker request;
2. clears the previous recommendation;
3. removes recommendation highlights/results;
4. marks score/recommendation output stale.

Presentation-only changes, such as theme or comparison tab, do not invalidate optimizer state.

## Engine boundary

`BoardState`, `OptimizerState`, layout definitions, operation definitions, transition mechanics, scoring, and search routing are owned outside the UI. UI modules may display legal choices and derived values supplied by those modules, but they do not reimplement them.

Production routing is:

- `legacy_3`, t=1/2 → full reference search;
- `expanded_5`, t=1 → full reference search;
- `expanded_5`, t=2 → validated `adaptive-tight` search with full-search fallback.

Synchronous engine APIs remain available for tests and non-browser consumers. Browser recommendations use the worker path.
